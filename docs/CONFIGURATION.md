# Configuration reference

`configs/reference_benchmark.json` records the benchmark version, method names, seed list, scenario list, analysis unit, and bootstrap settings. Scenario manifests are JSON arrays produced by `save_scenarios` and consumed by `load_scenarios`.

For archival runs, preserve the exact configuration, raw CSV, summary JSON, software version, Python version, NumPy version, and SHA-256 hashes. Do not edit generated summaries by hand.
